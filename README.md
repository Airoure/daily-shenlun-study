# 每日申论学习 Skill

这是一个面向 Codex 的每日申论学习陪练 skill，用于自动收集最新申论材料、生成训练题、批改答案、追踪薄弱项，并沉淀每日学习记录。

## 能做什么

- 从配置的信息源中收集最新政策、评论、基层案例和数据材料。
- 将材料加工成申论训练题。
- 支持归纳概括、综合分析、提出对策、公文写作、议论文/大作文训练。
- 在用户作答后给出档位判断、扣分点、最小修改版和参考答案。
- 自动维护每日学习记录和下一次训练任务。

## 默认信息源

- 国务院政策文件库
- 中国政府网政策解读
- 人民日报人民时评
- 半月谈
- 国家统计局
- 农业农村部乡村振兴和乡村治理相关栏目

信息源配置位于：

```text
references/sources.md
```

## 使用方式

在 Codex 中调用：

```text
使用 $daily-shenlun-study 开始今天的申论学习
```

也可以直接说：

```text
开始今天的申论训练
```

## 设计原则

- 默认主动收集材料，不要求用户每天自己提供材料。
- 先训练再给答案，避免直接看参考答案。
- 每天只做一个聚焦任务，避免铺开成泛泛课程。
- 反馈要具体到可修改动作。
- 学习记录要可延续，下一次任务必须明确。
