# Review Rubrics

Use these rubrics for practice scoring. Scores are approximate training judgments, not official exam marks.

## Common Review Dimensions

- 审题: 是否抓住题型、对象、范围、字数和身份。
- 要点: 是否覆盖材料中的主要问题、原因、影响、做法。
- 结构: 是否分类清楚、层次分明、顺序合理。
- 表达: 是否准确、简洁、规范，有申论语言。
- 执行性: 对策是否具体，有主体、动作、机制、结果。

## 归纳概括

High score:

- 要点全，分类准，语言压缩。
- 不照抄长句，不夹杂过多评论。
- 能把零散材料归入上位概念。

Common deductions:

- 漏掉核心对象或限制条件。
- 把原因、问题、对策混写。
- 句子太长，材料痕迹重。

## 综合分析

High score:

- 先解释对象或观点，再分析原因/意义/问题，最后落到启示或对策。
- 能兼顾材料事实和价值判断。
- 逻辑链完整。

Common deductions:

- 只复述材料，没有分析。
- 观点表态模糊。
- 原因和对策脱节。

## 提出对策

High score:

- 对策对应问题。
- 每条对策有主体、动作、机制和目标。
- 表述可执行，不空喊口号。

Common deductions:

- 对策泛化，如 "加强宣传、完善机制" 但没有抓手。
- 没有回应材料中的具体矛盾。
- 多条对策重复。

## 公文写作

High score:

- 符合文种、身份、对象和场景。
- 格式必要但不过度。
- 内容有背景、问题、措施或倡议，语气匹配。

Common deductions:

- 文种错位。
- 语气不像机关应用文。
- 格式占字过多，实质内容不足。

## 议论文/大作文

High score:

- 立意准确，紧扣材料主题。
- 分论点并列清楚，能支撑总论点。
- 论证有事实、政策、案例和分析，不只堆口号。
- 开头结尾简洁有力。

Common deductions:

- 标题和中心论点泛化。
- 分论点交叉或递进关系不清。
- 例子空泛，没有解释为什么能证明观点。
- 政策词很多但缺少问题意识。

## Feedback Priority

Give at most three main deductions in one review. Prioritize:

1. 跑题或审题错误。
2. 核心要点缺失。
3. 结构混乱。
4. 对策不可执行。
5. 表达冗长或口语化。

End every review with one rewrite task.
